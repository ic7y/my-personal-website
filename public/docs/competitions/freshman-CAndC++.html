★ 蓝桥杯备战学习计划

大一学生 · C++ / C 方向 · 海南省冲刺省级三等奖

📋 目标：海南赛区省三 · 4个月系统备战

🎯 目标拆解（海南省赛区）

海南赛区竞争压力相对较小，省三通常不需要高分。蓝桥杯省赛没有固定分数线，奖项按参赛人数比例划定，同时还会设最低获奖分数线。2026年起省赛奖项比例可能调整为 一等奖10%、二等奖15%、三等奖25%，总获奖率不超过50%。所以不要只盯着"30%"这个旧比例，更稳妥的目标是：稳定拿到前40%左右，并保证不是零分。

只要保证不做零分卷，做对1道填空题，并在1-2道编程题里拿到部分测试点，就有较大机会获得省三。若前3道编程题发挥稳定，甚至可以冲省二。

目标 具体做法 得分参考
保底不零分 每道题都提交，哪怕暴力枚举 避免直接出局
填空题拿1道 枚举、日期计算、简单模拟 10-15 分
编程题拿1-2道部分分 暴力、模拟、排序、贪心 20-30 分
冲省二 前3道编程题尽量做稳 40 分以上

⚔ 赛制与核心策略

省赛一般 4 小时，10 道题：5 道结果填空 + 5 道编程题。

冲刺省三的核心不是"全会"，而是：

  • 填空题尽量做对 1-2 道；
  • 编程题前 2-3 道争取拿满或接近满分；
  • 后面难题用暴力、模拟、枚举骗分；
  • 避免零分卷，零分不得奖。

📅 四个月学习计划（海南赛区版）

现在到明年4月省赛，时间比较合适。以下计划针对海南赛区特点定制，重点放在"稳拿基础分 + 骗分策略"上。

💡 第 1-4 周：语法 + 基础题感

  • 目标：能独立写循环、数组、字符串、结构体。
  • C++ 选手补 STL：vector、string、sort、queue。
  • 每天 1.5-2 小时，周末 4-6 小时。
  • 刷题：洛谷入门题 + 蓝桥杯练习系统基础题。

💡 第 5-8 周：枚举、模拟、排序、二分、前缀和

  • 目标：能稳定拿下填空题和前两道编程题。
  • 重点练：日期题、暴力枚举、字符串处理、简单贪心。
  • 每周 15-20 题，按专题刷。

💡 第 9-12 周：DFS/BFS、基础 DP、简单数论

  • 目标：提高编程题拿分上限。
  • 重点：连通块、迷宫、背包、线性 DP、GCD、素数、快速幂。
  • 每周 12-18 题，整理模板。

💡 第 13-16 周：真题模拟 + 骗分训练

  • 目标：适应 4 小时比赛节奏。
  • 每周做 2-3 套真题，严格限时。
  • 每套复盘：哪些题能拿满，哪些题能骗分，哪些题该放弃。
阶段 重点 每周任务

第5-8周

第9-12周

🕐 每周时间建议

  • 平时：每天 1.5-2 小时；
  • 周末：4-6 小时；
  • 期末周适当减少刷题，但不能完全停；
  • 不要只看书，一定要上机写代码。

📝 必须掌握的高频考点

优先学这些，性价比最高：

输入输出与基础语法 数组、字符串、结构体 枚举与模拟 蓝桥杯非常常见 排序与二分 快排、sort、二分答案 前缀和、差分 区间求和类题常用 DFS/BFS 迷宫、连通块、路径搜索 基础 DP 线性 DP、01 背包、完全背包 简单数论 GCD、LCM、素数判断、快速幂 日期/时间处理 蓝桥杯高频题型 STL vector、string、queue、stack、map、set、sort

🛠 刷题平台

  • 洛谷：按"入门""普及-"难度刷；
  • 蓝桥杯练习系统：熟悉真题和提交环境；
  • AcWing：有蓝桥杯专项题和专题训练；
  • 真题优先刷 C/C++ 大学 B 组，如果基础较弱可以先看 C 组题。

⚖ 考场策略

  • 先做填空题，再从前到后做简单编程题；
  • 编程题不要空着，暴力解也能拿测试点；
  • 填空题答案格式必须严格一致；
  • 注意 long long、数组越界、输入格式；
  • 考前用 Dev-C++ 练几套题，避免考场环境不适应。

⚡ 建议优先选 C++ 大学 B 组 作为主方向；如果 C 语言更熟，也可以报 C，但训练时尽量按 C++ 思路准备模板。省三的关键不是难题全会，而是把简单题做稳、难题能骗到分。海南赛区竞争压力相对较小，稳住基础分就有很大机会获奖！
